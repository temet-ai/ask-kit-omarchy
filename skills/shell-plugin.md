The Omarchy shell: bar layout, widgets, plugins, idle and lock, and what a plugin must do (safety, motion, translations)
1. Everything runs in one long-lived shell process (`omarchy-shell`). User settings: `~/.config/omarchy/shell.json`; canonical defaults: `omarchy.path + "/config/omarchy/shell.json"`; user plugins: `~/.config/omarchy/plugins/<plugin-id>/`. The shell reloads `shell.json` and plugin code on save.
2. `scripts.run("drift")` shows which shell.json settings the user changed from the default. `omarchy.run("refresh", "shell")` resets to the default (backs up; only when asked).
3. Idle and lock: `idle.screensaver` and `idle.lock` in shell.json are seconds since idleness began. "Lock after ten minutes" is `idle.lock` = 600.
4. Bar: sections in order are `left`, `centerBegin`, `center`, `centerEnd`, `right`, plus `tray` inside the tray drawer. A widget beside the clock goes in `centerBegin` or `centerEnd`, not `center`, or the clock leaves the middle. Move one with `omarchy.run("bar", "move", "omarchy.clock", "--section", "right")` (needs act).
5. To customise a built-in widget, never edit `omarchy.path + "/shell/plugins"`: `omarchy.run("plugin", "clone", "omarchy.workspaces")` copies it to `~/.config/omarchy/plugins/<username>.workspaces` and switches the bar to the copy. `omarchy-shell shell rescanPlugins` forces a reload (not run from here: tell the caller).
6. Plugin safety (the shell is long-lived and unsandboxed): QML `Text` defaults to AutoText, so untrusted text (network, files, IPC, settings, command output) must not reach it; set `textFormat: Text.PlainText`. Neutralise markup before passing dynamic text to an Omarchy component whose Text format you cannot set; never edit the packaged component. Bound and validate downloaded data (sizes, lengths, ids, timestamps). Network access is explicit: fixed HTTPS sources, timeouts, size limits, disclosed and switchable background refreshes; never run downloaded content or put untrusted values into shell commands. Add regression tests for markup-shaped input.
7. Plugin motion: build on `qs.Ui` (`KeyboardPanel`, `PopupCard`, `Button`) before animating anything. For your own animation `import qs.Commons` and give every duration as `Style.duration(ms)` (0 when the user turned animations off). Ease with `Style.easeOut` or `Easing.OutCubic`, never ease-in or bounce, under 300 ms with exits shorter than entrances (about 180 in, 120 out), start scale at 0.95 to 0.97 with opacity 0, never from 0. Do not animate what one keystroke opens many times a day.
8. Plugin translations: ship `i18n/<code>.json` beside the QML (`en.json`, `da.json`, `pt-BR.json`; `omarchy.path + "/default/i18n/locales.json"` lists the 50 codes) and read them through `Commons.Translations { directory: Qt.resolvedUrl("i18n") }`. A missing string falls back from `pt-BR` to `pt`, then `en`, then the key. Keep strings whole with `%1` placeholders; counted strings are objects keyed by CLDR category read with `strings.tn(key, count)`; format numbers with `Commons.I18n.formatNumber`; dates with `Qt.locale(Commons.I18n.formatLocale)`; keep `strings.t(...)` inside bindings; right-to-left languages mirror, so follow `LayoutMirroring.enabled` for explicit x positions.
